# 发布前完整检查清单

**适用版本：第八阶段部署边界加固｜更新：2026 年 9 月 18 日**

自动检查入口：

```powershell
cd D:\MeetingMind
.\scripts\pre_release_check.ps1 -ReportPath .\data\release-check\phase8-backup-monitoring-final-2026-09-18.json
```

该脚本不会打印或上传 `OPENAI_API_KEY`、`HF_TOKEN`、MySQL 密码；它只检查必要字段是否存在、服务是否可用、迁移是否位于 head、OpenAPI 是否符合关键契约，以及测试和构建是否通过。

- [x] `/openapi.json` 可读取，包含 `BearerAuth`、受保护业务操作、会议/任务/AI/导出接口、处理字段，以及上传和 AI 分析的显式确认字段。

- [x] `scripts/pre_release_check.ps1 -ReportPath ...` 生成不含敏感值的 JSON 检查报告，且 PowerShell 语法解析通过。
- [x] Docker Compose 配置校验通过；需要跳过时必须在命令中明确使用 `-SkipInfrastructure`。
- [x] 本地与生产 Caddyfile 通过固定版本解析；本地 HTTPS 健康接口和安全响应头通过；HTTP 正确跳转到 HTTPS。

## 发布判定原则

“测试通过”不自动等于“生产可发布”。本项目目前具备本地单机发布候选的功能闭环；若要面向多人、互联网或长期运行环境发布，仍必须完成正式身份授权、真实域名与可信证书现场验收、备份恢复、日志集中化、监控告警和容量治理。
