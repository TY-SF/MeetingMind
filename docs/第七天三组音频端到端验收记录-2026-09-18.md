## 样本与数据边界

本次使用三组由项目脚本生成的非敏感合成音频：

1. 清晰的结构化双人会议；
2. 包含建议、分歧和未确定表达的会议；
3. 包含轻微背景噪音、短暂重叠发言和英文技术术语的会议。

样本定义位于 `evaluation/audio_fixtures/`。生成的 WAV 文件和端到端预测结果位于被 Git 忽略的 `data/evaluation/`，不会进入版本库。

## 执行入口

```powershell
cd D:\MeetingMind

backend\.venv\Scripts\python.exe evaluation\run_end_to_end.py
backend\.venv\Scripts\python.exe evaluation\verify_day7_e2e_report.py
```

```text

→ Markdown/ICS 导出
→ 永久删除及 404 复核
```

## 限制

- 合成音频用于建立可重复、无隐私风险的工程验收基线，不替代真实授权会议上的质量评估；
- 本轮 pyannote 流程成功执行，但三组短合成音频均被识别为单一说话人。设计文档没有把说话人分离准确率设为第七天硬指标；映射能力已有独立自动测试和真实多人录音历史验收；
- 三组样本不具有生产环境统计代表性。
