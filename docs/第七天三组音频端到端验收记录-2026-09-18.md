## 样本与数据边界

本次使用三组由项目脚本生成的非敏感合成音频：

1. 清晰的结构化双人会议；
2. 包含建议、分歧和未确定表达的会议；
3. 包含轻微背景噪音、短暂重叠发言和英文技术术语的会议。

样本定义位于 `evaluation/audio_fixtures/`。生成的 WAV 文件和端到端预测结果位于被 Git 忽略的 `data/evaluation/`，不会进入版本库。
